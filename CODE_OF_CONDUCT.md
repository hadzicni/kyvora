# Code of Conduct

## Our pledge

We are committed to making Kyvora a welcoming and professional open-source
project for contributors with different backgrounds, experience levels, and
perspectives.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while staying clear and factual.
- Give and receive technical feedback professionally.
- Keep discussions focused on the project and its users.
- Respect maintainers' time and review capacity.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or conduct.
- Trolling, sustained disruption, or bad-faith participation.
- Publishing private information without permission.
- Repeatedly ignoring maintainer direction.

## Enforcement

Maintainers may remove comments, close issues or pull requests, restrict
participation, or take other reasonable action when behavior violates this code
of conduct. Enforcement decisions should be proportionate, consistent, and
focused on protecting the project community.

## Scope

This code of conduct applies in project spaces, including GitHub issues, pull
requests, discussions, documentation, and any other official Kyvora community
channels.
